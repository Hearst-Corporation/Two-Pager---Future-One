# Inspirations — 3D & Immersive Web

Bibliothèque personnelle de références pour construire des sites web 3D / WebGL ambitieux.
Curatée mai 2026.

## Comment utiliser ce dossier

1. **Avant de démarrer un projet** → parcourir `3d-websites/` pour caler le niveau d'ambition et trouver des refs visuelles précises.
2. **Pour choisir un partenaire / s'inspirer d'une approche** → `studios/` liste les studios de référence par spécialité.
3. **Pour choisir la stack technique** → `stack/` documente les libs combinables et les patterns qui marchent.
4. **Pour creuser** → `galleries/` (où trouver de nouvelles refs) et `tutorials/` (où apprendre).

## Règles de curation

- **Une ref = un lien direct + 2 lignes pourquoi c'est intéressant**. Pas de blabla.
- **Date toujours mentionnée** (mois/année). Le web 3D vieillit vite.
- **Marquer les refs "morphables"** : celles dont une technique précise est extractible (un effet, un pattern de scroll, un shader) vs celles à regarder pour le wow factor global.
- **Si une ref disparaît** (lien mort), la remplacer ou la supprimer plutôt que la laisser pourrir.
