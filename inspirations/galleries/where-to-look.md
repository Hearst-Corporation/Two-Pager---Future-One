# Where to look — galleries d'inspiration

Les sources où trouver de nouvelles refs 3D / web créatif. Ordre = qualité décroissante.

---

## Tier S — visite hebdo

### Awwwards
- **URL** : https://www.awwwards.com
- **Sections clés** :
  - SOTD (Site of the Day) : https://www.awwwards.com/websites/sites_of_the_day/
  - SOTM (Site of the Month) : https://www.awwwards.com/sites_of_the_month/
  - Collections 3D : https://www.awwwards.com/websites/3d/
  - Collections Three.js : https://www.awwwards.com/websites/three-js/
  - Annual Awards : https://www.awwwards.com/annual-awards/
- **Pourquoi tier S** : référence mondiale, scoring transparent, votes pros + jurys.
- **Caveat** : biais "Webflow + WebGL" depuis 2024 (Webflow sponsor).

### FWA (The FWA)
- **URL** : https://thefwa.com
- **Sections** : FWA of the Day, Player's Choice, Hall of Fame.
- **Pourquoi tier S** : plus ancien award (depuis 2000), exigence technique.
- **Caveat** : abonnement payant pour certains case studies.

### Codrops
- **URL** : https://tympanus.net/codrops
- **Sections** :
  - "Collective" hebdo (digest) : https://tympanus.net/codrops/collective/
  - Articles tech : tutos détaillés.
- **Pourquoi tier S** : la meilleure source d'articles techniques sur ce qui sort cette semaine. Curation parfaite.

## Tier A — visite mensuelle

### Godly Website
- **URL** : https://godly.website
- **Spécialité** : agrégateur clean, focus sur le créatif.
- **Force** : moins de bruit qu'Awwwards, vraies pépites.

### SiteInspire
- **URL** : https://www.siteinspire.com
- **Spécialité** : design web propre, pas que 3D.
- **Force** : variété de styles, taggé proprement.

### Land-book
- **URL** : https://land-book.com
- **Spécialité** : landing pages.
- **Force** : utile quand tu cherches des layouts spécifiques (hero, pricing, footer).

### Httpster
- **URL** : https://httpster.net
- **Spécialité** : fresh, daily, brutalist-leaning.
- **Force** : moins polished mais inspirant pour direction artistique.

### Minimal Gallery
- **URL** : https://minimal.gallery
- **Spécialité** : minimalisme propre. Anti-3D-tape-à-l-œil.
- **Pourquoi y aller** : équilibrer ta culture visuelle.

## Tier B — sources spécialisées

### Three.js Examples
- **URL** : https://threejs.org/examples/
- Code source de tout. Si tu veux comprendre comment un effet est fait, commence là.

### React Three Fiber Examples
- **URL** : https://r3f.docs.pmnd.rs/getting-started/examples
- Examples officiels R3F. Code dispo sur GitHub.

### Drei storybook
- **URL** : https://drei.docs.pmnd.rs
- Tous les helpers Drei avec démos live.

### Shadertoy
- **URL** : https://shadertoy.com
- Galerie de shaders. Pour reverse-engineer.

### CodePen — Three.js / WebGL filtré
- **URL** : https://codepen.io/topic/three-js
- Petits effets isolés, parfait pour copier un pattern précis.

### Webflow Showcase
- **URL** : https://webflow.com/discover
- Si tu pars sur du Webflow + WebGL custom.

### CSS Design Awards
- **URL** : https://www.cssdesignawards.com
- Concurrent d'Awwwards, plus axé brand.

### Best Website Gallery
- **URL** : https://bestwebsite.gallery
- Curation conservatrice mais propre.

## Workflow recommandé

1. **Daily** : flux Twitter/Threads (cf `creators.md`) → 5 min.
2. **Weekly** : Codrops Collective (sortie le vendredi) → 15 min.
3. **Monthly** : Awwwards SOTM annonces, FWA recap → 30 min.
4. **Quarterly** : Annual Awards Awwwards / FWA winners → 1h, sauver les refs dans ce dossier.
5. **Quand tu démarres un projet** : check ce dossier d'abord (5 min), puis Awwwards par tag pertinent (15 min).

## Outil pratique

**Browser bookmark folder** :
```
Inspirations/
├── Daily (Twitter list, Codrops Collective)
├── Weekly (Awwwards SOTD, FWA)
├── Galleries (Godly, Minimal, Httpster)
└── Tech (Three.js examples, Drei, Shadertoy)
```

Et sauvegarde les sites qui te marquent en signets — pas en simple "like" Twitter, sinon tu les perds.
