## Comment choisir un studio

Critères pratiques :

| Critère | Question à poser |
|---------|------------------|
| **Budget** | Tier S (Lusion, Active Theory) = $150k–$1M+. Tier A (OFF+BRAND, Noomo) = $50k–$300k. |
| **Délai** | Sites primés = 3–9 mois minimum. Si on te promet 6 semaines, c'est du template. |
| **Maintenance** | Qui maintient après livraison ? Le code est-il propre/transmissible ? |
| **Sources** | Demandent-ils accès à Figma/photos HD/mood board ? Si non, méfiance. |
| **Performance** | Demande explicitement les targets : 60fps desktop, 30fps mid-mobile, < 4s LCP. |

## Red flags studio

- "On utilise [skill IA] pour générer la 3D" → pas un studio, un revendeur.
- Pas de case studies > 12 mois → pas de longévité.
- Stack 100% Webflow sans custom code → plafonne vite sur du 3D ambitieux.
- Pas de dev WebGL en interne → ils sous-traitent, qualité aléatoire.
