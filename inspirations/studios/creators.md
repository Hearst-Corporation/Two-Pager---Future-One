## Comment utiliser cette liste

1. **Twitter/Threads list** : crée une liste privée avec tous ces comptes → un seul flux à scroller 5 min/jour.
2. **YouTube** : abonne-toi à akella + Wawa Sensei + Bruno Simon. Notif sur Wawa Sensei (pédagogie moderne).
3. **Bookmark** : Maxime Heckel blog + Codrops → quand tu cherches "comment faire X effet", commence par eux.
4. **Cours payant qui en vaut la peine** : Three.js Journey (Bruno Simon) si tu veux vraiment maîtriser. ~$95, lifetime.
