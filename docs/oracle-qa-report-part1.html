EXECUTIVE SUMMARY

ORACLE contains 48 P0 blockers that collectively make it unsuitable for any founder, investor, or board-facing use in its current state. The three most dangerous failure modes converge on a single trust catastrophe: the chat advisor is systematically ungrounded (quick-prompt answers invent numbers from corpus benchmarks while ignoring live engine output), the waterfall preferred-return accrual is mathematically wrong (over-accrues exponentially instead of compounding on the running balance), and there is zero investment-advice disclaimer anywhere in the output pipeline — an institutional deliverable containing IRR, MOIC, NPV, and explicit PROCEED/REJECT verdicts without a non-reliance notice is a regulatory liability in every target market. Compounding this: the title field is never sent to the memo API so every auto-generated memo is labeled with a truncated LLM headline; archetype selection is never persisted so reopening a scenario silently reverts the operating model; and a Supabase error during memo persistence returns HTTP 200 with no ID, routing the user to /dossier?memo=undefined. The design system has dual token definitions in two CSS files that produce non-deterministic visual output for every semantic color, spacing step, and border radius in the cockpit. Until the P0 financial math bugs, the trust/disclaimer gap, and the three critical grounding failures are resolved, this product cannot be shown to a single investor.
